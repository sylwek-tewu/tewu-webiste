## Review Focus

1. **Measurement safety:** every `tel:`/`mailto:` link that exists today still exists (same targets; only order changes where Task 1 says so); no `dataLayer` event, id or `data-*` attribute removed or renamed (except the `topic: 'fundacja'` value removed by Task 9).
2. **Indexing:** production host `tewu.szczecin.pl` must never get `noindex`; every other host must. A wrong regex here either de-indexes the live site or leaks preview copies.
3. **Forbidden content:** no „doradztwo podatkowe” (or UK equivalents) in metadata/headings/JSON-LD; no `AggregateRating`/`Review`; no invented facts.
4. **JSON-LD injection:** serialized JSON-LD must escape `<` so page copy cannot close the `<script>`.
5. **UK parity:** every PL change has its UK counterpart; no Polish text left on `/uk` pages touched by the tasks.
